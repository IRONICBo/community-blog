Jev Social: bounded decisions, real browser evidence

Jev Social uses Jev Choice decisions to route an Instagram, TikTok, or LinkedIn goal and select each next read-only operation. The local socai CLI executes the operation in the user's Chrome session, while captured posts, media, and source links stream into an inspectable report.

Jev only selects from exact operations and observed targets supplied by the program; it never writes shell commands or arbitrary selectors, and malformed or low-confidence decisions do not execute. Version 0.1.3 also packages this boundary as an installable Agent Skill for Codex and compatible agents.
